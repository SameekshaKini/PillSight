# PillSight — Deep Learning Pill Identification

**ADSP 31018 | University of Chicago | Prof. Arnab Bose**

A deep learning system that identifies pills from photos. Upload an image, get back the top predicted medication with a confidence score. Built as a multi-model comparison project — four team members, four architectures, one shared dataset.

---

## What it does

A user photographs an unknown pill and the model returns its top predictions. The motivation is real: patients, caregivers, and first responders regularly encounter unlabeled pills and have no quick way to identify them. Most existing apps rely on imprint text, which fails when pills are worn or broken. A vision-based approach works even then.

This project is a proof-of-concept research tool, not a clinical product. It should never replace a licensed pharmacist.

## Dataset

We use the **ePillID dataset** from the NIH National Library of Medicine. It contains reference images of thousands of FDA-approved pill types, each photographed from the front and back.

### Download

1. Download **ePillID_data.zip** (153MB) from the official release:
   https://github.com/usuyama/ePillID-benchmark/releases/tag/ePillID_data_v1.0
2. Unzip it — you should get a `data/` folder containing `all_labels.csv` and `classification_data/`
3. Move that `data/` folder to the project root (same level as `model1_cnn/`)

The repo expects this exact folder structure:

```
ML class project/
├── data/
│   ├── all_labels.csv
│   └── classification_data/
│       ├── segmented_nih_pills_224/
│       └── fcn_mix_weight/
├── model1_cnn/
└── ...
```

The `data/` folder sits at the project root, one level above `model1_cnn/`. Do not put it inside `model1_cnn/`.

### What we actually use

Out of the full dataset we filter down to:
- `is_ref = True` rows only (clean reference photos, not consumer images)
- `segmented_nih_pills_224/` subfolder only (white-background segmented images, already 224x224)
- Top 10 manufacturer groups (`label_code_id`) by image count — 2,312 images total

This filtering happens automatically when you run `data_exploration.py`.

## Running Model 1 (CNN baseline)

Run these four scripts in order from inside the `model1_cnn/` folder:

```bash
cd model1_cnn
```

#### Step 1 — Filter the dataset and select classes
```bash
python data_exploration.py
```
Reads `all_labels.csv`, filters to reference segmented images, picks the top 10 classes, and writes `filtered_metadata.csv` and `class_map.json` to the `data/` folder. Run this once before anything else.

#### Step 2 — Train the model
```bash
python train.py
```
Trains the CNN for 20 epochs with Adam and class-weighted cross-entropy loss. Saves the best checkpoint (by validation accuracy) to `checkpoints/best_model.pth`. Also saves a learning curve plot to `outputs/`.

Training takes roughly 20–40 minutes on CPU. If you have a GPU it will be significantly faster.

#### Step 3 — Evaluate on the test set
```bash
python evaluate.py
```
Loads the best checkpoint and runs it on the held-out test set. Prints Top-1 accuracy, Top-3 accuracy, and macro F1. Saves a confusion matrix PNG to `outputs/`.

#### Step 4 — Grad-CAM visualizations
```bash
python gradcam.py
```
Generates heatmap overlays for 5 test images showing which regions of each pill drove the model's prediction. Saves to `outputs/gradcam/`.

## Adjusting the number of classes

Change the single constant in `model1_cnn/config.py`:

```python
NUM_CLASSES = 10  # change to 15 to expand
```

Then re-run `data_exploration.py` to regenerate the filtered dataset, and restart from `train.py`.
